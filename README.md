# AI Study Platform 🤖📚

An AI-powered desktop study assistant built with **Python, CustomTkinter, and Google Gemini**.

## Features

-  User login and registration
-  Subject management
-  AI Tutor powered by Gemini
-  AI-powered explanations and answers
-  Study activity tracking
-  Modern CustomTkinter interface
-  Responsive AI processing using threading

## Tech Stack

- Python
- CustomTkinter
- Google Gemini API
- JSON
- Threading
- Object-Oriented Programming

## Project Purpose

The platform is designed to help students organize their studies and get instant AI assistance while learning.

## Future Improvements

- PDF study material analysis
- AI-generated quizzes and MCQs
- Study planner
- Progress tracking
- Weak-topic detection
- Chat history
